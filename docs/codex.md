# plan-review in OpenAI Codex

Install it as the [README](../README.md#codex) shows. Then run `$ship <issue number, link or prompt>` in Codex; `plan-review upgrade` updates both parts. What differs from Claude Code: Codex has no background watcher, so the agent runs `plan-review serve <id> --detach` (the viewer is its own process, and stops 2 hours after its page closes) and waits with `plan-review wait`, about every 4 minutes while you are away. Codex's sandbox must allow network access, or `gh` and `uv` fail and the viewer can't listen on `127.0.0.1`: in `~/.codex/config.toml` set `network_access = true` under `[sandbox_workspace_write]` (or use a sandbox mode that has it). The agents read `AGENTS.md`; if your project keeps its rules in `CLAUDE.md` only, set `project_doc_fallback_filenames = ["CLAUDE.md"]` in the same file so Codex reads them. To override an agent for one project, put `.codex/agents/<name>.toml` in it. Not tested in Codex's own sandbox yet: run `$ship` once and report what you see.
